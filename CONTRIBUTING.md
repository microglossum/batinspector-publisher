# Contributing / Mitwirken

## English

This is a one-person project and I'm not actively looking for code contributions.

What is welcome:

* **Bug reports and questions**: open an issue (English or German). Please leave out tokens, client secrets and real roost coordinates.

Build and test: `dotnet build`, `dotnet test` (.NET 10 SDK plus the .NET 8 runtime; the devcontainer has both).

## Deutsch

Das ist ein Ein-Personen-Projekt, und ich suche aktiv keine Code-Beiträge.

Willkommen sind:

* **Fehlermeldungen und Fragen**: ein Issue öffnen (Englisch oder Deutsch). Bitte keine Tokens, Client-Secrets oder echten Quartierkoordinaten angeben.

Bauen und testen: `dotnet build`, `dotnet test` (.NET-10-SDK plus .NET-8-Runtime; der Devcontainer bringt beides mit).
