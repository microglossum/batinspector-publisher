# Security policy / Sicherheitsrichtlinie

**English:** Please report vulnerabilities privately through GitHub: *Security* tab, *Report a vulnerability*
(private vulnerability reporting). Do not open a public issue and do not post tokens or client secrets anywhere.
Only the latest release receives fixes while the package is in `0.x`.

**Deutsch:** Sicherheitslücken bitte privat über GitHub melden: Reiter *Security*, *Report a vulnerability*
(private Meldung). Kein öffentliches Issue anlegen und keine Tokens oder Client-Secrets irgendwo posten.
Solange das Paket in `0.x` ist, erhält nur die neueste Version Korrekturen.
